# Roadmap

## Fase 1 — Loja única Brasil Drones

- App single-tenant tenant-ready.
- Store ID nas tabelas.
- Loja pública.
- Painel admin básico.
- Catálogo.
- Produtos/categorias.
- Carrinho/pedido.
- Bling modular.
- Logs.
- Design premium.

- Templates editáveis.

- Domínio customizado.
- Melhor Envio.
- Mercado Pago.
- Recomendações básicas.
- Área do comprador.

## Fase 3 — SaaS multi-tenant

- Tenants.
- Onboarding de loja.
- Planos.
- Billing.
- Painel master.
- Subdomínios automáticos.
- Domínio próprio self-service.
- Multi-loja.

- Marketplace de apps.

## Fase 5 — Plataforma avançada
