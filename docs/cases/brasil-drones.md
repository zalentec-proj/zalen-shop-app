# Case — Brasil Drones

## Visão

Brasil Drones & Parts é a primeira loja real construída sobre a Zalen Shop.

Este case valida o core da plataforma com uma loja customizada, catálogo técnico, admin operacional e integração planejada com o Bling.

## Tipo

- Storefront customizado.
- Admin Zalen Shop.
- ERP: Bling.
- Status: primeiro cliente/case.

## Identidade

O storefront usa a identidade Brasil Drones.

O login e o admin usam identidade Zalen Shop, com Brasil Drones apenas como contexto da loja ativa.

## Escopo do case

- Home Brasil Drones.
- Página de produto.
- Página de categoria.
- Carrinho.
- Admin de produtos.
- Admin de pedidos.
- Admin de integrações.
- Supabase Cloud.
- Bling planejado como ERP.

## Integração principal

### Bling

O Bling será o ERP operacional da Brasil Drones.

Responsabilidades previstas:

- produtos;
- categorias;
- estoque;
- pedidos;
- status;
- webhooks;
- logs de integração.

## Regras

- Brasil Drones não deve ter código específico acoplado ao core.
- Customização visual fica no storefront.
- Dados operacionais passam pelo core Zalen Shop.
- Integração com Bling passa pelo conector Bling.
